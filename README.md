# Reservations-App

Reservations App is a web application for managing medical appointments and reservations. It allows users to explore available services, view healthcare professionals, create new reservations, and monitor appointments from a central dashboard.

The application uses an Excel file as a test database. Professionals and services are loaded from `data.xlsx`, while new reservations are automatically saved in the corresponding worksheet.

## Features

- Dashboard with appointment and reservation statistics.
- Table displaying all registered reservations.
- Healthcare professional directory.
- Available medical services.
- New appointment registration.
- Excel-based data storage.
- Automatic calculation of today's appointments and pending reservations.
- Responsive interface for desktop and mobile devices.

## Technologies

- React
- Vite
- Material UI
- Axios
- Java
- Spring Boot
- Apache POI
- Microsoft Excel for test data storage
